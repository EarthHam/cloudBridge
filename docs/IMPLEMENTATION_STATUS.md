# cloudBridge 实现状态

更新日期：2026-11-16

## 已实现

### 应用与界面

- 独立 Electron/Vite/Vue 3 应用；全部 Vue 单文件组件采用 Options API，未使用 TypeScript 或 Composition API。
- 首次使用向导、实例仪表盘、Cloud Sat/高级转发编辑器、TLS 管理、日志诊断、设置与版本信息。
- 五种实例模板、复制、启动、停止、重启、全部启动/停止、运行错误显示、连接地址复制及二维码。
- 简体中文和英文文案键同步。
- 主窗口关闭到托盘，退出时有序停止实例、关闭音频宿主并释放资源。

### 主进程与协议

- 版本化 JSON 配置、原子写入、Zod 运行时校验、`safeStorage` 密钥加密。
- 实例操作按实例串行化，防止并发重复启动；部分启动失败会清理运行时及资源租约。
- 通配地址端口冲突、跨实例串口/音频冲突、单实例重复串口选择检测。
- Cloud Sat 和高级转发均仅允许本机及直接连接的私有子网访问，HTTP 健康检查同样受保护。
- Cloud Sat 固定路径、协议 v2 认证、来源限流、单客户端限制、ping/pong 与错误消息。
- 音频帧头、序列号、PCM16 完整样本和 64 KiB 总帧限制。
- 隐藏音频窗口、MessagePort 有界音频投递、多 AudioWorklet 会话、播放缓冲与指标。
- WebSocket/TCP 源、持久 TCP 目标、1–30 秒退避、串口 30 ms 静默分帧与 64 KiB 上限。
- 监听地址采用四项固定选择；`::` 显式启用 IPv4/IPv6 双栈，系统禁用 IPv6 时回退到全部 IPv4。
- TLS 证书解析、证书/私钥匹配、尚未生效和过期校验；仅 Cloud Sat / WebSocket 监听端支持 TLS，TCP 模式明确标注未加密并清理无效证书关联。
- 受限 preload API、沙盒、上下文隔离及音频窗口专属媒体权限。

### 构建资产

- 原创 `build/icon-source.png`。
- 1024×1024 PNG、macOS ICNS、Windows 多尺寸 ICO、托盘 PNG。
- MAS 沙盒 entitlement 和 Windows MSIX 配置。
- 精确依赖版本、npm lockfile、安全安装脚本和依赖审计脚本。

## 仍需目标环境验收

以下项目不能由当前无硬件、无商店签名凭据的开发环境替代，发布前必须执行：

- 两套真实声卡和两台真实串口设备并发运行、拔插、权限拒绝与恢复。
- macOS/Windows 睡眠唤醒、网络切换和防火墙场景。
- 用户提供的可信 WSS 证书链在真实控制端上的互通测试。
- 四个 Cloud Sat 加四个高级转发任务的长时间压力测试及 2 小时内存/句柄观察。
- Apple Universal MAS 签名、描述文件、沙盒包内串口/麦克风测试和 Transporter 验证。
- Windows x64 MSIX 签名、安装/升级/卸载和 WACK 验证。
- 商店审核专用的无硬件演示数据模式尚未实现；目前 E2E 使用无硬件 TCP 转发实例完成审核路径验证。

## 已知边界

- 通用 TCP 目标在暂时离线时保持实例运行并持续退避重连；连接期间到达但目标尚未在线的数据不会无限缓存。
- 声卡设备缺失时不会回退到系统默认设备。
- 日志按内存条目上限滚动重写；诊断十六进制临时开关尚未提供 UI。
- 商店版本不包含第三方自动更新器。
